The bootstrapper has to find the running Roblox client and attach to it. Two Roblox settings
routinely get in the way, and leftover files from previous installs cause the rest of the
"it injected once and never again" reports.

Do this page after [Preparation & Prerequisites](/guide/preparation/) and before your first
attempt at [Execution & Injection](/guide/injection/).

<Aside type="tip" title="Why these two settings matter">
  - **Launch on startup** lets Roblox open itself at login, so you end up with a
  client running before the bootstrapper is ready for it. - **Minimize to tray
  when closed** keeps a hidden Roblox process alive after you close the window.
  The bootstrapper can't tell that client apart from a stale one, which is what
  causes injection to silently do nothing.
</Aside>

## Step 1 - Disable Launch on startup

<Steps>

1. Open Roblox and open its **Settings** menu (the gear icon inside the app, or press `Esc`
   while in a game and open the settings tab).

2. Find **Launch on startup** and switch it **off**. The exact label can differ slightly
   between Roblox versions -look for the option that makes Roblox open itself when Windows
   starts.

3. Leave the settings menu open for the next step.

</Steps>

## Step 2 - Disable Minimize to tray when closed

<Steps>

1. In the same settings menu, find **Minimize to tray when closed** and switch it **off**.

2. If you see something like **Close Roblox to system tray** instead, that's the same option.

3. Close the settings menu so the change is saved.

</Steps>

## Step 3 - Fully close Roblox

Both settings above only take effect on a fresh start, so clearing out any existing client is
part of the job.

<Steps>

1. Close the Roblox window normally.

2. Check the **system tray** (the arrow near the clock) for a Roblox icon. If it's there,
   right-click it and choose **Close/Exit**. With the tray setting now off, this should be the
   last time it appears.

3. Open Task Manager with `Ctrl` `Shift` `Esc` and look through the process list for anything
   named **Roblox** -`RobloxPlayerBeta` is the usual one.

4. End any Roblox process you find, then confirm the list stays empty.

5. Reopen Roblox and close it once more to verify it now closes completely instead of hiding
   in the tray.

</Steps>

<Aside type="caution">
  If a Roblox process keeps reappearing after you end it, you're almost
  certainly still hitting the tray setting from step 2, or Roblox is being
  relaunched by a scheduled task from "Launch on startup". Re-check both before
  moving on.
</Aside>

## Step 4 - Clear a stale install (only if needed)

If you've had SirHurt installed before, or injection has stopped working after previously
working, old files are the likely cause. The SirHurt Cleaner wipes them.

<Steps>

1. Download the [SirHurt Cleaner](https://github.com/i-nagap/Sirstrap/releases/) -it ships
   bundled with Sirstrap.

2. Make sure Roblox is fully closed first (step 3).

3. Run the cleaner and press `Y` followed by `Enter` for **every** prompt. Answering only some
   of them leaves the remnants behind, which defeats the point.

4. Let it finish, then confirm your SirHurt folder no longer contains leftover binaries.

</Steps>

<Aside type="danger" title="This clears your auth data">
  The cleaner removes SirHurt's stored authentication along with the old files,
  so you'll need to log in again on your next injection. That's expected, not a
  sign that something broke.
</Aside>

## Step 5 - Handle version errors

If SirHurt reports that you're on an unsupported version, Roblox has been updated past the build
SirHurt has been patched for. This is normal immediately after a Roblox release.

<Steps>

1. Check the announcements channel in our [Discord](https://discord.gg/sirhurt) for the
   currently supported build.

2. Note the recommended build hash -it looks like `version-c5aecda2245e4fae`.

3. Follow the [Downgrade Tutorial](/guide/downgrade/) to install that build, or open the
   [Downgrade Thingamabob 6000](/rdd/) and use **Download Previous Version**, which tracks the current
   downgrade target for you.

4. Repeat from step 1 if Roblox updates again before you finish.

</Steps>

## Step 6 - Verify before continuing

<Steps>

1. **Launch on startup** is off.

2. **Minimize to tray when closed** is off.

3. No Roblox processes remain in Task Manager after closing the app.

4. Roblox has been reopened at least once since the settings were changed.

5. If you ran the Cleaner, it completed with `Y` and `Enter` on all prompts.

</Steps>

Once this list is clean, move on to [Execution & Injection](/guide/injection/). If injection
still fails afterwards, [Troubleshooting](/guide/troubleshooting/) works through each symptom
individually.
