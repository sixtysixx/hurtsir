Two Roblox settings routinely get in the way of the loader attaching to a running client, so turn
them off now and close Roblox completely before you install anything.

**Stage 2 of 4.**

<Aside type="tip" title="Why these two settings matter">

- **Launch on startup** lets Roblox open itself at login, so you end up with a client running
  before the loader is ready for it.
- **Minimize to tray when closed** keeps a hidden Roblox process alive after you close the window.
  The loader can't tell that client apart from a stale one, which is what causes injection to
  silently do nothing.

</Aside>

## Step 1 — Disable Launch on startup

<Steps>

1. Open Roblox and open its **Settings** menu (the gear icon inside the app, or press `Esc` while
   in a game and open the settings tab).

2. Find **Launch on startup** and switch it **off**. The exact label can differ slightly between
   Roblox versions — look for the option that makes Roblox open itself when Windows starts.

3. Leave the settings menu open for the next step.

</Steps>

## Step 2 — Disable Minimize to tray when closed

<Steps>

1. In the same settings menu, find **Minimize to tray when closed** and switch it **off**.

2. If you see something like **Close Roblox to system tray** instead, that's the same option.

3. Close the settings menu so the change is saved.

</Steps>

## Step 3 — Fully close Roblox

Both settings above only take effect on a fresh start, so clearing out any existing client is part
of the job.

<Steps>

1. Close the Roblox window normally.

2. Check the **system tray** (the arrow near the clock) for a Roblox icon. If it's there,
   right-click it and choose **Close/Exit**. With the tray setting now off, this should be the last
   time it appears.

3. Open Task Manager with `Ctrl` `Shift` `Esc` and look through the process list for anything named
   **Roblox** — `RobloxPlayerBeta` is the usual one.

4. End any Roblox process you find, then confirm the list stays empty.

5. Reopen Roblox and close it once more to verify it now closes completely instead of hiding in the
   tray.

</Steps>

<Aside type="caution">
  If a Roblox process keeps reappearing after you end it, you're almost
  certainly still hitting the tray setting from step 2, or Roblox is being
  relaunched by a scheduled task from "Launch on startup". Re-check both before
  moving on.
</Aside>

<Aside type="tip" title="Roblox can reset these settings">
  A Roblox update can quietly turn **Launch on startup** or **Minimize to tray when closed** back
  on. If injection suddenly stops working, re-check this page first — it costs a minute.
</Aside>

## Step 4 — Before you continue

<Steps>

1. **Launch on startup** is off.

2. **Minimize to tray when closed** is off.

3. No Roblox processes remain in Task Manager after closing the app.

4. Roblox has been reopened at least once since the settings were changed.

5. Roblox is not running right now.

</Steps>
