Almost every SirHurt problem traces back to one of five causes: an unsupported Roblox version, a
Roblox setting the loader can't work around, antivirus interference, missing prerequisites, or
leftovers from an earlier install.

<Aside type="tip" title="This page is a lookup, not a stage">
  Work the five checks first; then find the symptom you're actually seeing. Don't read it
  front-to-back — the sections overlap, and following two fixes at once makes it harder to tell
  which one worked.
</Aside>

<Aside type="tip" title="Run these five checks first">

1. You're on Windows **24H2** or newer.
2. Roblox **"Launch on startup"** and **"Minimize to tray when closed"** are both disabled — see
   [stage 2](/guide/roblox-settings/).
3. Your SirHurt folder is in your antivirus **exclusions** — see [stage 1](/guide/preparation/).
4. The loader is being started **as Administrator** — see [stage 4](/guide/injection/).
5. You wait **5-10 seconds** after joining a game before injecting.

If all five are true and it still fails, jump to the matching symptom below.

</Aside>

## "Unsupported version" / version check fails

SirHurt only works on Roblox builds it has been updated for. Right after a Roblox update, the build
you're on is usually too new.

<Steps>

1. **Run the loader again first.** SirHurt is usually patched for a new Roblox build shortly after
   it ships, so a fresh run often picks up support for the build you're already on.

2. If that fixed it, you're done. If not, check the announcements channel in our
   [Discord](https://discord.gg/sirhurt) for the currently supported version and its build hash
   (it looks like `version-abc123cbt4204mee`).

3. Install that build — either follow [Version Mismatch & Downgrade](/guide/downgrade/) or open the
   [Downgrade Thingamabob 6000](/rdd/) and click **Download Previous Version**, which tracks the
   target for you. Close Roblox fully, including the tray icon, before replacing anything.

4. Launch the downgraded build, join a game, wait 5-10 seconds, then inject. If it still reports an
   unsupported version, the build was updated again in the meantime — repeat from step 2.

</Steps>

## Injection doesn't work after clicking Inject

<Steps>

1. Confirm all five checks above are still true, especially the two Roblox settings.

2. Close Roblox completely, including the tray icon, then reopen it.

3. Join any game and wait **5-10 seconds** so the client is fully loaded.

4. Run the SirHurt loader **as Administrator**.

5. Click **Inject** once and log in when prompted. **Do not click Inject again** — the loader
   finishes on its own.

6. Execute a test script such as **Infinite Yield** to confirm the injector is live.

</Steps>

## Injection used to work, now it doesn't

Leftover files from an earlier install are the usual cause. The SirHurt Cleaner wipes them.

<Steps>

1. Download the [SirHurt Cleaner](https://sirstrap.com/) — it ships bundled with Sirstrap.

2. Make sure Roblox is fully closed first (see [stage 2](/guide/roblox-settings/)).

3. Run the cleaner and press `Y` followed by `Enter` for **every** prompt. Answering only some of
   them leaves the remnants behind, which defeats the point.

4. Let it finish, then confirm your SirHurt folder no longer contains leftover binaries, and
   re-extract SirHurt as described in [stage 3](/guide/install/).

</Steps>

<Aside type="danger" title="This clears your auth data">
  The cleaner removes SirHurt's stored authentication along with the old files,
  so you'll need to log in again on your next injection. That's expected, not a
  sign that something broke.
</Aside>

## The loader hangs, won't open, or closes instantly

<Steps>

1. Open the SirHurt UI and use the **Kill Processes** button to clear stuck Roblox and loader
   processes.

2. If the UI is unresponsive, end `RobloxPlayerBeta` and the loader from Task Manager
   (`Ctrl` `Shift` `Esc`) instead.

3. Start the loader as **Administrator** again.

4. Add a **folder exclusion** for your SirHurt folder in your antivirus settings. An instant close
   is usually the scanner deleting a file while the loader is still loading it — see
   [antivirus flags](#antivirus-flags-quarantines-or-deletes-sirhurt-files).

5. Re-download SirHurt from the link on [sirhurt.net](https://sirhurt.net/) rather than reusing an
   older copy, so you're not starting from a partial install.

6. Extract the download with **7-Zip** or **WinRAR**. Windows' built-in extractor leaves the DLLs
   marked as blocked, which stops the loader from starting.

7. Re-run the [SirHurt Cleaner](https://sirstrap.com/) (bundled with Sirstrap) and press `Y` +
   `Enter` for every prompt. This wipes leftover files from older installs.

8. Reinstall **both x86 and x64** of the
   [Visual C++ Redistributables](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version)
   and the [.NET SDK](https://dotnet.microsoft.com/en-us/download), then **restart your PC**.

</Steps>

<Aside type="caution">
  Running the Cleaner will clear your SirHurt auth data, so you'll need to log
  in again afterwards.
</Aside>

## Antivirus flags, quarantines, or deletes SirHurt files

Injectors are routinely flagged by antivirus scanners, so this is expected noise rather than proof
of anything malicious — but it will break your install every time the scanner acts.

<Steps>

1. Open your antivirus **quarantine/history** and restore anything related to SirHurt if it was
   removed.

2. Create a dedicated folder for SirHurt and add it to your antivirus **Exclusions / Whitelist**.

3. Re-download any missing files from official sources only — never from mirrors or random
   reuploads.

4. Re-run the loader as Administrator to confirm it now launches and stays open.

</Steps>

## Scripts don't execute after a successful injection

<Steps>

1. Confirm the injection actually succeeded — the loader UI should report a successful attach, not
   sit at "waiting".

2. Make sure Roblox is within a game, not at the home screen.

3. Execute a known-good, maintained script such as **Infinite Yield** first, so you know the
   injector works and any failure is the script's fault.

4. Check the announcements channel in our [Discord](https://discord.gg/sirhurt) for known script
   outages before assuming your setup is at fault.

</Steps>

## Downloads from the Downgrade Thingamabob 6000 fail

<Steps>

1. Read the log panel. The downloader reports the exact HTTP status for each failure, which tells
   you whether the problem is your network or Roblox's CDN.

2. If **Download Latest Version** fails, retry with **Download Previous Version**. Roblox sometimes
   publishes a build before all of its files are downloadable, and the previous build is usually
   the one SirHurt wants anyway.

3. If you're targeting a specific executor, put its name in the **Version Hash** field's companion
   query using `?exploit=<name>` — RDD resolves the build that executor is pinned to.

4. On repeated network errors, try **Cloudflare WARP** — the log panel links it directly under the
   error.

5. Make sure you have enough free disk space: the assembled archive is several hundred MB, and it's
   built in memory in your browser.

</Steps>

## Roblox won't launch, or opens a black/blank window

<Steps>

1. Kill every Roblox process, including the tray process, then relaunch.

2. Check the Roblox settings again — **"Launch on startup"** in particular can leave a stale
   session fighting your new one.

3. Repair your system files by running the chain from [stage 1](/guide/preparation/) in an
   **Administrator PowerShell**, then restart.

4. If Roblox still won't start, reinstall it, then repeat the setup steps from
   [stage 1](/guide/preparation/) before injecting again.

</Steps>
